# Security policy

This tool runs system mutations as root and can affect login, suspend,
drivers, and boot-time configuration.

Please report security issues privately through GitHub's **Security →
Advisories → Report a vulnerability** flow for this repository. Include the
affected commit or release, reproduction steps, and the system files involved.
Do not open a public issue until a fix is available.

Security fixes are supported for the latest tagged release and the `main`
branch. Workarounds that require a reboot or affect PAM receive priority.
