# Attributions

Tweaks for CachyOS is built with open-source software from the Charm ecosystem:

- [Bubble Tea](https://github.com/charmbracelet/bubbletea) provides the
  terminal application architecture.
- [Bubbles](https://github.com/charmbracelet/bubbles) provides reusable
  interface components.
- [Lip Gloss](https://github.com/charmbracelet/lipgloss) provides terminal
  layout and styling.
- [Glamour](https://github.com/charmbracelet/glamour) renders the in-app
  document center.

These projects and the frontend's transitive dependencies use compatible
permissive licenses. Complete notices for the dependencies linked into the
distributed binary are bundled in `THIRD_PARTY_LICENSES/`.

The CachyOS name and visual identity belong to the CachyOS project. This
application uses its own terminal artwork and is independently maintained. It
is not affiliated with, maintained by, or endorsed by the CachyOS project.
